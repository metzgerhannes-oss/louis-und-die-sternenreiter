# Child Creator – Louis als Sternenformer

## Grundidee

Der Creator ist kein separates Entwicklermenü.

Er ist eine Fähigkeit von Louis innerhalb der Spielwelt.

Das Kind erlebt:

> Idee → Louis → Rückfragen → Ergebnis

Intern kann daraus entweder eine direkte Spieländerung oder ein späterer Entwicklungsauftrag entstehen.

## Vier Umsetzungsstufen

### A – Sofort formen
Kleine, vorbereitete Änderungen werden direkt sichtbar.

### B – Bauen
Materialien werden benötigt. Louis baut nach Bestätigung.

### C – Sternenformen
Größere, ortsgebundene Änderungen benötigen Sternenstaub und eine passende Freigabe des Sternenpunkts.

### D – Große Idee
Nicht sofort umsetzbare Inhalte werden ins Ideenbuch übernommen und durchlaufen den Reviewprozess.

## Kernfluss am Sternenpunkt

```
Sternenpunkt erkannt
→ Louis erklärt Kontext
→ Kind spricht oder schreibt Idee
→ Louis stellt Rückfragen
→ strukturierter Entwurf
→ Weltregeln prüfen
→ Umsetzungsstufe bestimmen
→ A/B/C: im Spiel umsetzen
→ D: Ideenbuch / Review / Entwicklungsbacklog
```

## Louis-Sprache

Louis vermeidet Entwicklerbegriffe.

Nicht:
- Canon
- Issue
- Pull Request
- JSON
- Datenbank
- Asset

Stattdessen:
- „Das kann ich hier direkt bauen.“
- „Dafür fehlen uns noch Teile.“
- „Dafür brauche ich Sternenstaub.“
- „Das ist größer als dieser Ort. Ich schreibe es in unser Ideenbuch.“
- „Die Sternenbauer schauen sich unsere Idee an.“
- „Unsere Idee passt jetzt zur Sternenkarte.“

## Weltregelkonflikte

Louis lehnt Ideen nicht trocken ab.

Beispiel:
Kind:
> „Hier soll ein riesiger Vulkan mitten im Hangar sein.“

Louis:
> „Ein Vulkan würde Hangar 3 ziemlich gründlich zerlegen. Soll er vielleicht draußen auf einem neuen Planeten stehen? Oder bauen wir hier nur ein kleines Vulkan-Modell?“

Das System versucht:
1. Intention verstehen
2. Konflikt erklären
3. passende Alternative anbieten
4. Originalidee erhalten

## Große Idee / Review

```
Kind
→ Louis
→ strukturierter Entwurf
→ Weltregelprüfung
→ Ideas-Datenbank
→ Erwachsenenreview
→ GitHub-Backlog
→ Umsetzung
→ Canon-Revision
→ Louis meldet dem Kind, dass die Idee Teil der Welt geworden ist
```

## Status im Kinderbereich

Mögliche Anzeigen:
- „Louis schreibt noch.“
- „Idee gespeichert.“
- „Die Sternenbauer schauen sie sich an.“
- „Sie haben noch eine Frage.“
- „Die Idee wird gebaut.“
- „Die Idee ist jetzt auf der Sternenkarte.“

Technische Statuswerte bleiben intern.

## Rückverfolgbarkeit

Jede große Idee behält:
- Originalwortlaut
- bestätigtes Transkript
- Louis-Rückfragen
- strukturierte Fassung
- Weltregelprüfung
- Reviewänderungen
- Umsetzungsreferenz
- Canon-Revision
